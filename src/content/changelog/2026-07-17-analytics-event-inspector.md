- Built an in-app developer tool for the Android app that mirrors analytics/tracking events in real time, so you can watch precisely what fires as you tap through a flow — no more guessing whether an event actually sent.
- Each event is tagged with which analytics backend emitted it, and the whole captured stream can be exported and shared as JSON, so a tracking bug can be handed off with the receipts attached.
- Fixed a debug-view toggle that had been failing silently — flipping it on now reliably does what the label promises.
- On this site: added an animated knowledge-graph on the home page, driven by real data mined from my own git history showing how AI-assisted development has grown across my repos.
